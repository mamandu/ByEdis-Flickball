# ByEdis-Flickball
 "Minimalist physics game recreated from wooden original"

## Controls
- **Left-click** near ball to aim
- **Right-click** to shoot
- First to 10 goals wins

## Features
- Realistic physics
- VS AI mode
- Monochrome minimalist design
- Golden ratio proportions

## About
Originally crafted from wood, now available as a web game.
